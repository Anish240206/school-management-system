# School Management System

A full-stack modernization of my Class XII Computer Science project.

## Project History

The original version was developed in **Class XII (2023–24)** as a console-based Python application using MySQL. It implemented basic school-management operations for students, teachers, attendance, fees, and the library.

The original code is preserved in:

`history/old-reference/school_management_system_class12.py`

The long-term goal of this repository is to evolve the project into a deployed full-stack application while keeping the original implementation available as a record of where the project started.

## Planned Stack

- **Frontend:** React + Vite
- **Backend:** Python + FastAPI
- **Database:** MySQL
- **Deployment:** Cloud-hosted frontend, backend, and database
